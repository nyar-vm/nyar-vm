# nyar-types

Common type definitions and utilities for the Nyar virtual machine.

## Features

- **Core Types**: Definitions for Nyar's internal data structures.
- **Error Handling**: Unified error types for the entire ecosystem.
- **Serialization**: Built-in support for `serde`.
- **GC Integration**: Types designed to work seamlessly with `nyar-gc`.
