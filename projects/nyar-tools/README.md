# nyar-tools

A collection of command-line tools for working with the Nyar virtual machine.

## Features

- **REPL**: Interactive shell for testing Nyar code.
- **Compiler**: CLI for compiling source files to bytecode or native code.
- **Dump**: Utility for inspecting bytecode files.
- **Bench**: Benchmarking tools for performance analysis.
