# nyar

The primary entry point and CLI for the Nyar virtual machine ecosystem.

## Features

- **Multi-language Support**: Supports various frontends including C, Java, Python, and more.
- **Unified Interface**: One tool to run, compile, and manage Nyar projects.
- **High Performance**: Leverages the full power of `nyar-vm` and its JIT/AOT capabilities.
