# compiler / expansion

**语言规定的结构化展开**：模板、derive、元数据注入等，在 AST/HIR 边界上增加或改写树节点，并保留生成来源与 span。

## 子模块

| 模块 | 典型能力 |
|------|----------|
| `derive` | 派生代码生成钩子 |
| `meta_reactive` | 响应式元数据 |
| `route_injector` / `atlas_injector` | 路由与图注入 |

## 与声明索引的关系

若展开 **新增声明**，必须使声明索引与相关查询失效并重新求值；禁止在 HIR lowering 深处静默插入声明而不更新索引。

展开时机：

- **纯语法**展开可在类型分析之前（仍须走 Oak 结构化节点）。
- 依赖已绑定类型、常量或配置的展开，应向 `semantic` 请求结果后再执行。

## 边界

- Asgard **产品**代码生成（HTML/小程序壳等）不在此目录。
- 禁止为展开而全文正则重扫源码。
