# nyar-vm

The core virtual machine implementation for the Nyar project.

## Features

- **Bytecode Execution**: Efficient virtual machine for executing Nyar bytecode.
- **AOT Support**: Integrated support for Ahead-of-Time compilation.
- **Flexible Runtime**: Pluggable runtime and platform abstractions.
- **Strong Typing**: Built on top of `nyar-types` for consistent data representation.

## Usage

Add this to your `Cargo.toml`:

```toml
[dependencies]
nyar-vm = "0.1.0"
```
