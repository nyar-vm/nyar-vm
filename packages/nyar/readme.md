# @nyar/nyar

The command-line interface for the Nyar VM.

## Overview

This package provides the `nyar` command, which is the primary tool for running, compiling, and managing projects on the Nyar VM.

## Installation

```bash
npm install -g @nyar/nyar
```

## Usage

```bash
nyar --help
```

## Platform Support

This package automatically downloads the appropriate native binary for your platform:
- Windows (x64)
- Linux (x64)
- macOS (x64, ARM64)
- WebAssembly (WASI)
