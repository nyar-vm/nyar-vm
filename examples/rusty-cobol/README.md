# rusty-cobol

A COBOL language frontend for the Nyar virtual machine.

## Overview

This project implements a compiler frontend for the COBOL language, allowing COBOL source code to be compiled and executed on the Nyar virtual machine.

## Features

- **COBOL Syntax**: Support for classic COBOL syntax and divisions.
- **Nyar Integration**: Compiles COBOL code to Gaia IR for execution on the Nyar VM.
