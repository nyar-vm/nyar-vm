# rusty-mojo

A Mojo language frontend for the Nyar virtual machine.

## Overview

This project implements a compiler frontend for the Mojo language, allowing Mojo source code to be compiled and executed on the Nyar virtual machine.

## Features

- **AI/Systems**: Support for Mojo's performance-oriented AI and systems programming features.
- **Nyar Integration**: Compiles Mojo code to Gaia IR for execution on the Nyar VM.
