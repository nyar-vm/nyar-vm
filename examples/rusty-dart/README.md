# rusty-dart

A Dart language frontend for the Nyar virtual machine.

## Overview

This project implements a compiler frontend for the Dart language, allowing Dart source code to be compiled and executed on the Nyar virtual machine.

## Features

- **Dart Syntax**: Support for Dart's structured syntax.
- **Nyar Integration**: Compiles Dart code to Gaia IR for execution on the Nyar VM.
