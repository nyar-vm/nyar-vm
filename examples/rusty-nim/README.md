# rusty-nim

A Nim language frontend for the Nyar VM.

## Overview

This project implements a compiler frontend for the Nim language, allowing Nim source code to be compiled and executed on the Nyar VM.

## Features

- **Efficient/Expressive**: Support for Nim's combination of performance and high-level expressiveness.
- **Nyar Integration**: Compiles Nim code to Gaia IR for execution on the Nyar VM.
