# rusty-fsharp

An F# language frontend for the Nyar virtual machine.

## Overview

This project implements a compiler frontend for the F# language, allowing F# source code to be compiled and executed on the Nyar virtual machine.

## Features

- **Functional-First**: Support for F#'s functional-first programming paradigm.
- **Nyar Integration**: Compiles F# code to Gaia IR for execution on the Nyar VM.
