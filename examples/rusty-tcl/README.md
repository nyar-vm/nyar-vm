# rusty-tcl

A TCL language frontend for the Nyar VM.

## Overview

This project implements a compiler frontend for the TCL language, allowing TCL source code to be compiled and executed on the Nyar VM.

## Features

- **Scripting/Tooling**: Support for TCL's simple yet powerful scripting capabilities.
- **Nyar Integration**: Compiles TCL code to Gaia IR for execution on the Nyar VM.
