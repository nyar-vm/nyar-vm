# Mini C 语言编译器

这是一个轻量级的 C 语言编译器前端实现，作为 Gaia 项目的示例，旨在验证从 C 语言源代码到多种二进制格式（特别是 PE 和 ELF）的编译流程。

## 核心目标

- **全流程验证**：验证从 C 源代码解析、中间代码生成到最终生成 PE (Windows) 或 ELF (Linux) 可执行文件的完整路径。
- **跨平台兼容性**：测试 Gaia 编译器后端在不同操作系统环境下的表现。

## 支持特性

### 语言特性
- **声明**：支持函数定义、变量声明、结构体声明以及基础预处理器指令。
- **控制流**：支持 `if-else`、`while`、`for` 循环，以及 `switch-case`、`goto` 和标签。
- **表达式**：
  - 算术、逻辑、位运算、赋值运算。
  - 函数调用、数组索引、成员访问（`.` 和 `->`）。
  - 三元运算符 `? :`、`sizeof` 和显式类型转换。
- **类型系统**：
  - 基础类型：`int`, `char`, `short`, `long`, `float`, `double`, `void`。
  - 复合类型：指针、数组、结构体、联合体、枚举。
  - 支持 `typedef`。

### 编译器功能
- 词法分析 (Lexer) 与语法分析 (Parser)。
- 抽象语法树 (AST) 生成与序列化。
- Gaia 指令集 (Gaia IR) 生成。
- 直接生成可执行二进制文件。

## 快速开始

### 安装依赖
确保已安装 Rust 工具链。

### 使用方法
```bash
# 编译并运行
cargo run -- <input.vc> [选项]
```

### 常用选项
- `-o, --target <FILE>`: 指定输出文件路径。
- `--tokens`: 仅输出词法分析结果。
- `--ast`: 仅输出抽象语法树 (AST)。
- `--gaia`: 输出生成的 Gaia 指令。
- `--binary`: 直接生成 PE/ELF 二进制文件。
- `--json`: 以 JSON 格式输出 Gaia 指令。

## 项目结构
- `src/ast/`: 抽象语法树定义。
- `src/lexer/`: 词法分析器实现。
- `src/parser/`: 语法分析器实现。
- `src/codegen/`: 从 AST 到 Gaia 指令的生成逻辑。
- `tests/`: 测试用例（`.vc` 文件）。
