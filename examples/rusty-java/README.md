# rusty-java

A Java language frontend for the Nyar virtual machine.

## Overview

This project implements a compiler frontend for the Java language, allowing Java source code to be compiled and executed on the Nyar virtual machine.

## Features

- **Object-Oriented**: Support for Java's class-based object-oriented model.
- **Nyar Integration**: Compiles Java code to Gaia IR for execution on the Nyar VM.
