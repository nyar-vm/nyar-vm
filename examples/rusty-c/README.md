# rusty-c

A C language frontend for the Nyar virtual machine.

## Overview

This project implements a compiler frontend for the C language, allowing C source code to be compiled and executed on the Nyar virtual machine.

## Features

- **Preprocessor**: Support for C preprocessor directives.
- **Standard Syntax**: Support for standard C syntax and control flow.
- **Nyar Integration**: Compiles C code to Gaia IR for execution on the Nyar VM.
