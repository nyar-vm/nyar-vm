# rusty-scheme

A Scheme language frontend for the Nyar VM.

## Overview

This project implements a compiler frontend for the Scheme language, allowing Scheme source code to be compiled and executed on the Nyar VM.

## Features

- **Minimalist Lisp**: Support for Scheme's elegant and minimalist Lisp dialect.
- **Nyar Integration**: Compiles Scheme code to Gaia IR for execution on the Nyar VM.
