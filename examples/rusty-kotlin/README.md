# rusty-kotlin

A Kotlin language frontend for the Nyar virtual machine.

## Overview

This project implements a compiler frontend for the Kotlin language, allowing Kotlin source code to be compiled and executed on the Nyar virtual machine.

## Features

- **Modern JVM**: Support for Kotlin's concise and safe syntax.
- **Nyar Integration**: Compiles Kotlin code to Gaia IR for execution on the Nyar VM.
