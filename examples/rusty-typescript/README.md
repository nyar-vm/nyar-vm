# rusty-typescript

A TypeScript language frontend for the Nyar virtual machine.

## Overview

This project implements a compiler frontend for the TypeScript language, allowing TypeScript source code to be compiled and executed on the Nyar virtual machine.

## Features

- **Strongly Typed JS**: Support for TypeScript's type system on top of JavaScript.
- **Nyar Integration**: Compiles TypeScript code to Gaia IR for execution on the Nyar VM.
