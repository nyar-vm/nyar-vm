# rusty-r

An R language frontend for the Nyar VM.

## Overview

This project implements a compiler frontend for the R language, allowing R source code to be compiled and executed on the Nyar VM.

## Features

- **Statistical Computing**: Support for R's specialized syntax for statistical computing and graphics.
- **Nyar Integration**: Compiles R code to Gaia IR for execution on the Nyar VM.
