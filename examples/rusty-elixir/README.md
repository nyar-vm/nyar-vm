# rusty-elixir

An Elixir language frontend for the Nyar virtual machine.

## Overview

This project implements a compiler frontend for the Elixir language, allowing Elixir source code to be compiled and executed on the Nyar virtual machine.

## Features

- **Functional/Concurrent**: Support for Elixir's functional and concurrent programming models.
- **Nyar Integration**: Compiles Elixir code to Gaia IR for execution on the Nyar VM.
