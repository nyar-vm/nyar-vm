# rusty-fortran

A Fortran language frontend for the Nyar virtual machine.

## Overview

This project implements a compiler frontend for the Fortran language, allowing Fortran source code to be compiled and executed on the Nyar virtual machine.

## Features

- **Scientific Computing**: Support for Fortran's specialized syntax for scientific computing.
- **Nyar Integration**: Compiles Fortran code to Gaia IR for execution on the Nyar VM.
