# rusty-go

A Go language frontend for the Nyar virtual machine.

## Overview

This project implements a compiler frontend for the Go language, allowing Go source code to be compiled and executed on the Nyar virtual machine.

## Features

- **Concurrent Programming**: Support for Go's concurrency primitives.
- **Nyar Integration**: Compiles Go code to Gaia IR for execution on the Nyar VM.
