# rusty-julia

A Julia language frontend for the Nyar virtual machine.

## Overview

This project implements a compiler frontend for the Julia language, allowing Julia source code to be compiled and executed on the Nyar virtual machine.

## Features

- **Dynamic/Technical**: Support for Julia's dynamic yet high-performance technical computing features.
- **Nyar Integration**: Compiles Julia code to Gaia IR for execution on the Nyar VM.
