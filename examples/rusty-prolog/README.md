# rusty-prolog

A Prolog language frontend for the Nyar VM.

## Overview

This project implements a compiler frontend for the Prolog language, allowing Prolog source code to be compiled and executed on the Nyar VM.

## Features

- **Logic Programming**: Support for Prolog's logic programming paradigm.
- **Nyar Integration**: Compiles Prolog code to Gaia IR for execution on the Nyar VM.
