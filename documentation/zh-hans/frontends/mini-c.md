# Mini C

Mini C 是一个简化版的 C 语言前端实现，专注于展示过程化编程语言在 Nyar VM 上的映射。

## 核心特性

- 基础数据结构：`int`, `char`, `void` 指针。
- 控制流：`if`, `while`, `for`, `switch`。
- 函数定义与外部函数调用（FFI）。
- 简单的预处理器支持。

## 编译流程

1. **词法/语法分析**: 使用 `oak-rust` 生成的解析器。
2. **语义检查**: 基础的类型检查与符号表维护。
3. **UIR 生成**: 将 C 语言的命令式结构转换为 `IKun` 意图流。
4. **后端发射**: 通过 `NyarAot` 生成原生二进制。
