# Valkyrie 编译器中间表示架构

Valkyrie 编译器采用多层中间表示（IR）架构，为语言提供高效的编译和优化基础设施。通过四层渐进式转换，Valkyrie 能够将高级语言特性转换为优化的目标代码，支持 WebAssembly、JavaScript 和原生代码等多种执行环境。

## 编译器架构概览

### 设计目标

Valkyrie 编译器的设计专注于：
- **表达力转换**: 将复杂的函数式和代数效应特性安全地降级
- **多级优化**: 提供从高级语义到低级指令的多层层次优化
- **跨平台支持**: 统一的后端架构，支持多种目标平台
- **开发工具链**: 为 IDE 和调试器提供精准的元数据支持

### 编译流水线 (Compilation Pipeline)

Valkyrie 的编译过程被建模为从源代码到机器码的渐进式降级过程：

#### 1. 前端 (Frontend - Oaks)
- **输入**: 源代码
- **输出**: AST (Abstract Syntax Tree) -> HIR (High-level IR)
- **职责**: 语法解析、名称解析、类型检查、Trait 特化、模式匹配解糖。
- **实现**: [oak-valkyrie](file:///e:/普遍优化/oaks/examples/oak-valkyrie)

#### 2. 中间表示降级 (Lowering - Chomsky UIR)
- **输入**: HIR
- **输出**: UIR (Universal Intermediate Representation / IKun)
- **职责**: 将高级语义图转换为基于 E-Graph 的通用中间表示，为全局优化做准备。
- **实现**: [valkyrie-compiler](file:///e:/普遍优化/valkyrie.rs/projects/valkyrie-compiler)

#### 3. 优化器 (Optimizer - Nyar VM / Chomsky)
- **输入**: UIR
- **输出**: 优化后的 UIR (IKun Tree)
- **职责**: 无论是 AOT 还是 JIT 模式，所有的核心优化任务（常数折叠、死代码消除、循环优化等）均由 **Nyar VM** 驱动的 **Chomsky 优化引擎** 完成。
- **特点**: 基于 E-Graph 的等价饱和（Equality Saturation）技术，能够发现传统编译器难以触及的深度优化空间。
- **实现**: [ProjectChomsky](file:///e:/普遍优化/ProjectChomsky)

#### 4. 后端生成 (Backend - Nyar VM / Gaia)
- **输入**: 优化后的 UIR
- **输出**: 目标机器码 (AOT) 或 内存可执行代码 (JIT)
- **职责**: 寄存器分配、指令选择、栈帧管理及最终代码发射。
- **实现**: [nyar-vm](file:///e:/普遍优化/nyar-vm) 与 [project-gaia](file:///e:/普遍优化/project-gaia)

## 各层中间表示的职责

### [AST - 抽象语法树](./ast/index.md)

AST 层作为编译器的入口点，接收来自语法解析器的语法树，并提供统一的语言特性抽象：

- **语言特性映射**: 将源代码的语法结构映射到结构化的 AST 节点
- **错误恢复**: 提供健壮的语法错误报告和恢复机制
- **工具支持**: 为 LSP 提供精确的源代码位置信息

**支持的核心特性**:
- 函数式编程：函数定义、闭包、高阶函数
- 面向对象：类、接口、继承、多态
- 泛型编程：类型参数、约束、特化
- 模式匹配：枚举、解构、守卫条件
- 代数效应：效应声明、处理器、恢复

### [HIR - 高级中间表示](./hir/index.md)

HIR 层是语义分析的核心，负责将 AST 转换为带有完整类型和语义信息的中间表示：

- **类型系统**: 执行复杂的类型推导和静态检查
- **语义分析**: 处理名称解析、作用域分析和借用检查
- **语义降级**: 将高级语法糖转换为更基础的语义形式

**架构优势**:
- 类型系统的严格验证
- 语义错误的精确诊断
- 智能感知代码补全的支持

### [MIR - 中级中间表示](./mir/index.md)

MIR 层是优化的核心，将高级语义转换为控制流图（CFG），进行深度的程序分析：

- **控制流构建**: 将复杂控制结构（如效应处理器、循环）转换为基本块图
- **数据流分析**: 基于 SSA 形式进行常量传播、死代码消除等优化
- **所有权分析**: 在中级层次处理资源的生命周期和移动语义

### [LIR - 低级中间表示](./lir/index.md)

LIR 层是代码生成的核心，为多种目标平台提供统一的低级抽象：

- **指令选择**: 针对虚拟指令集进行优化选择
- **多后端支持**: 统一生成 WebAssembly、JavaScript 或原生机器码
- **平台特定优化**: 针对不同执行环境（如浏览器、WASI）进行微调

## 编译器的核心价值

Valkyrie 通过这套多层架构，确保了代码在保持高级抽象的同时，能够获得接近原生的执行性能。开发者可以利用代数效应等前沿特性，而不必担心运行时的性能损耗，因为编译器会在转换过程中通过深度的静态分析将其优化为高效的控制流。
